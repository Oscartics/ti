# Temporizador corporativo

Abre `index.html` en un navegador moderno. Usa los botones para elegir una duración y pulsa **Iniciar**. El botón de la esquina superior derecha activa pantalla completa; también puedes usar la barra espaciadora para pausar/continuar y `R` para reiniciar.

La interfaz está diseñada para llenar pantallas Full HD y se adapta a tamaños menores. Los colores, textos y duraciones se pueden modificar directamente en `style.css`, `index.html` y `script.js`.

El aviso final usa la Web Audio API, por lo que no requiere un archivo `ding.mp3` externo.
